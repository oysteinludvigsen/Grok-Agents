Quick Start

  1. Run the setup script This generates icons & installs the native messaging host.
    # macOS / Linux python3 setup.py # Windows (PowerShell) python setup.py
  2. Verify the connection Click Re-check above — you should see a green dot.
  3. Configure your settings Click the Grok Agent icon in the toolbar to set your working directory, preferred shell, and timeout.
  4. Paste the template prompt into Grok Copy the prompt below and paste it at the start of a new Grok conversation (or save it as a Grok template).
  5. Give Grok a task! Grok will output agent:shell blocks. The extension detects them, runs the command locally, and feeds the result back.

How It Works

  1. Grok outputs a tool block e.g. ```agent:shell followed by a command
  2. The content script detects it A MutationObserver watches the page for new code blocks
  3. You confirm (or auto-execute runs it) A dialog shows the command; you approve or deny
  4. The native host executes it Via zsh, bash, or PowerShell in your configured working directory
  5. The result is fed back stdout/stderr are typed into the chat as an agent:result block
  6. Grok continues It reads the result and decides the next step — fully agentic loop
